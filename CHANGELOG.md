## 0.0.1

### New features

- Zero-loophole core authentication middleware with constant-time Bearer token and SameSite session cookie validation across all endpoints (`/api/*`, `/images/*`, `/mcp`). ([#2](https://github.com/seeramsujay/kanzo-plus-plus/pull/2))
- Native Android app built in Kotlin 2.0+ and Jetpack Compose Material 3 with AES-256-GCM rendezvous tunnel and Fortinet bypass via Pinggy SSH. ([#1](https://github.com/seeramsujay/kanzo-plus-plus/pull/1), [#2](https://github.com/seeramsujay/kanzo-plus-plus/pull/2))
- Obsidian-dark authentication login modal in browser web UI with automatic session renewal. ([#2](https://github.com/seeramsujay/kanzo-plus-plus/pull/2))
- CLI `kanzo token` and `kanzo token --reset` commands with POSIX `0600` atomic file persistence. ([#2](https://github.com/seeramsujay/kanzo-plus-plus/pull/2))
- Full distribution repointing of installers (`kanzo-installer.sh`, `kanzo-installer.ps1`), self-updaters, and documentation to `seeramsujay/kanzo-plus-plus`. ([#2](https://github.com/seeramsujay/kanzo-plus-plus/pull/2))
